How it works

A request to /v1/chat/completions (or /v1/messages) flows through the control plane in order:

  1. Authenticate

    Your virtual key (issued in the API Keys tab) is verified. Every tenant is rate-limited per key via Redis.

  2. Cache lookup

    Three tiers — exact match, then semantic similarity (embeddings), then a short-lived provider KV cache. Cache hits skip the providers entirely.

  3. Compress

    Long prompts are losslessly compressed to a token budget, cutting cost before the request even leaves the network.

  4. Guardrails

    PII (Aadhaar, PAN, phone, email, cards) is redacted pre-provider; JSON Schema output is enforced on the way back.

  5. Route

    Language-aware routing sends Hindi / Tamil / Telugu / Marathi to Sarvam-1. Complexity routing picks the right model for the job, with an automatic fallback chain.

  6. Budget check

    CostGuard compares the agent's monthly budget. At thresholds it alerts, auto-downgrades to a cheaper model, or hard-blocks with HTTP 402.

  7. Trace & bill

    Every step — LLM call, MCP tool call, retry, cache hit — is priced in INR and recorded as an OpenTelemetry span and usage event.

What it gives you

  • Unified LLM gateway — OpenAI- and Anthropic-compatible endpoints for Cursor, Claude Desktop, OpenCode, or your own agents.
  • MCP gateway — register MCP servers once (/v1/mcp/registry), invoke tools with auth, rate limits and health checks.
  • Cost intelligence — per-run traces in INR: tokens, tool calls, retries, and cache/compression savings.
  • Budget enforcement — per-agent monthly caps, alert thresholds, auto-downgrade and optional hard limits.
  • Guardrails — PII redaction and JSON Schema structured output at the gateway layer.
  • Observability — OpenTelemetry spans, a Python SDK, and a live trace view for every agent run.

Try it in 30 seconds

1 · Issue a virtual key from the API Keys page (admin-only) and copy the returned sk… value:

curl -X POST {{ request.base_url }}v1/admin/keys \ -H "Authorization: Bearer $ADMIN_API_KEY" -H "Content-Type: application/json" \ -d '{"name":"my-agent"}'

2 · Chat through the gateway (it prices, traces, caches & guards every call):

curl -X POST {{ request.base_url }}v1/chat/completions \ -H "Authorization: Bearer sk-..." -H "Content-Type: application/json" \ -d '{"model":"auto","messages":[{"role":"user","content":"Explain what this gateway does in one line"}]}'

3 · Invoke an MCP tool through the gateway:

curl -X POST {{ request.base_url }}v1/mcp/invoke \ -H "Authorization: Bearer sk-..." -H "Content-Type: application/json" \ -d '{"server":"local_tools","tool":"echo","arguments":{"text":"hello"}}'

4 · Watch the calls land in the dashboard:

open {{ request.base_url }}dashboard
