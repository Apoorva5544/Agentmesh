terminal Drop-in Replacement

Change one URL.
Gain instant control.

AgentMesh exposes OpenAI- and Anthropic-compatible REST endpoints, so standard SDKs (including LangChain) work with a one-line base_url swap — activating routing, guardrails, and telemetry on every call.

1 Zero agent refactoring required
2 Universal MCP (Model Context Protocol) support
3 Native Python SDK with OpenAI- & Anthropic-compatible REST endpoints
agent_runner.py
Python SDK 
from openai import OpenAI

# 1. Point a standard SDK at your gateway endpoint
client = OpenAI(
    base_url="{{ request.base_url }}v1",
    api_key="sk-your-virtual-key"  # Issue one via /v1/admin/keys
)

# 2. Call with any model — the gateway authenticates, caches, compresses & routes
response = client.chat.completions.create(
    model="gpt-4o-mini",  # e.g. openai, anthropic, sarvam, ollama
    messages=[
        {"role": "user", "content": "ग्राहक का खाता विवरण और KYC स्थिति सत्यापित करें"}
    ],
    extra_headers={
        "X-AgentMesh-Budget-Cap-INR": "50.00",
        "X-AgentMesh-PII-Guard": "aadhaar,pan,phone"
    }
)

# >> Authenticated, rate-limited, traced, and attributed in ₹
# >> Response lands in the dashboard under Recent Runs & Spend by Agent
print(response.choices[0].message.content)
