What this project does

Unified LLM gatewayOpenAI-compatible /v1/chat/completions, SSE streaming, semantic cache, prompt compression, model routing
MCP gatewayRegister MCP servers once, invoke tools via /v1/mcp/invoke with auth, rate limits, health checks & cost attribution
Cost intelligencePer-run traces in ₹(INR): LLM tokens, tool calls, retries, cache & compression savings
Budget enforcementPer-agent monthly budgets, alert thresholds, auto-downgrade, optional HTTP 402 hard limit

ObservabilityOpenTelemetry spans, Python SDK, live agent-run traces

Try it in 30 seconds

1 · Issue a virtual key (admin-only) and copy the returned sk… value:

curl -X POST {{ request.base_url }}v1/admin/keys \ -H "Authorization: Bearer $ADMIN_API_KEY" -H "Content-Type: application/json" \ -d '{"name":"my-agent"}'

2 · Chat through the gateway (it prices, traces, caches & guards every call):

curl -X POST {{ request.base_url }}v1/chat/completions \ -H "Authorization: Bearer sk-..." -H "Content-Type: application/json" \ -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Explain what this gateway does in one line"}]}'

3 · Invoke an MCP tool through the gateway:

curl -X POST {{ request.base_url }}v1/mcp/invoke \ -H "Authorization: Bearer sk-..." -H "Content-Type: application/json" \ -d '{"server":"local_tools","tool":"echo","arguments":{"text":"hello"}}'

4 · Watch the calls land in the dashboard:

open {{ request.base_url }}dashboard
